NoFutureData

A zero-dependency temporal leakage guard for Python and Jupyter. Make the historical information boundary executable in CI.

View on GitHub Latest release Rule reference

Point-in-time

Separate event time from known_at and eligible_from, then fail closed when a historical decision sees unavailable data.

Static guard

Scan Python and Jupyter for negative shifts, backfills, centered windows, and forward/nearest as-of joins.

Runtime proof

Mutate or delete only future rows and verify that already-produced historical outputs stay invariant.

Catch the leak before the metric looks amazing

Leaking
# tomorrow's price in today's feature
lead = price.shift(-1)

# future rows in a centered window
smooth = price.rolling(7, center=True).mean()
